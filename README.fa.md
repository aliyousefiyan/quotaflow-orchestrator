# QuotaFlow Orchestrator — راهنمای فارسی

این پروژه یک کنترل‌کننده مستقل و کم‌هزینه برای **توزیع اجرای کارهای قطعی بین چند مخزن GitHub Actions با مالکیت‌های جداگانه** است.

**مهم:** سهمیه Actions به **مالک مخزن** تعلق می‌گیرد، نه کاربری که دکمه Run را زده است. برای بهره‌گیری از ظرفیت سه حساب مجاز، باید سه مخزن اجرایی مستقل و متعلق به همان حساب‌ها داشته باشیم. انتقال غیرمجاز داده یا تلاش برای دور زدن مقررات سرویس مجاز نیست.

## کارهایی که نسخه فعلی انجام می‌دهد

- ثبت کار در صف SQLite با شناسه و ورودی تغییرناپذیر؛ تکرار ثبت کار، آن را دوباره اجرا نمی‌کند.
- اولویت‌بندی و بررسی ظرفیت واقعی ثبت‌شده هر حساب؛ برای اطلاعات نامعلوم یا قدیمی‌تر از ۱۲ ساعت اجرای هزینه‌دار ممنوع است.
- انتخاب مالک مناسب بر اساس سهمیه و رزرو اضطراری؛ حداکثر یک کار فعال در هر حساب.
- تأیید هویت مالک حساب GitHub، مالکیت مخزن، معتبر بودن Workflow و قرارداد Worker.
- اجرای **حداکثر یک** کار با تأیید صریح `--approve-dispatch`؛ پیگیری نتیجه با `sync`.
- جلوگیری از ارسال مجدد خودکار در صورت قطع شبکه بعد از درخواست، تا هزینه دوبرابر ایجاد نشود.
- امکان اجرای تست‌های خود نرم‌افزار بدون Work و Codex و بدون کلید API.

## نصب و آزمایش

```bash
python -m unittest discover -s tests -t . -v
python -m quotaflow --config examples/accounts.example.json --budgets examples/budgets.unknown.json --state demo.sqlite3 enqueue --file examples/jobs.example.json
python -m quotaflow --config examples/accounts.example.json --budgets examples/budgets.unknown.json --state demo.sqlite3 plan
```

برای اتصال واقعی، فایل الگو را به `accounts.json` و `budgets.json` کپی کنید، نام مالک و مخازن خود را وارد کنید و برای هر حساب توکن مجاز را **فقط در متغیر محیطی** نگهدارید. دستور `doctor` تأیید دسترسی را انجام می‌دهد؛ اجرای واقعی صرفاً با `dispatch --approve-dispatch` انجام می‌شود.

## ارتباط با Codex و Work

این دو قابلیت سهمیه مشترک OpenAI دارند و به صورت خودکار قابل افزایش با استفاده از سه حساب GitHub نیستند. برنامه‌های بک‌تست و اسکریپت‌های آماده می‌توانند در Actions مستقل اجرا شوند؛ ولی تولید کد جدید با هوش مصنوعی همچنان تابع سهمیه Work/Codex است. سهمیه واقعی آن‌ها در نسخه فعلی باید از رابط حساب بررسی شود. هیچ عدد ساختگی به سیستم داده نمی‌شود.

## وضعیت انتشار

نسخه 0.1.0 یک **پروژه متن‌باز قابل تست و توزیع** است. اتصال عملی سه Worker، اجرای خودکار بدون دخالت اپراتور و استفاده در پروژه‌های معاملاتی فعال هنوز انجام نشده و به بررسی مستقل دسترسی‌ها، سهمیه‌ها، نسخه‌های فعال و امنیت نیاز دارد. کد برای معاملات واقعی یا ارسال سفارش طراحی نشده است.
